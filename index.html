Règlement officiel

Règles à respecter par tous

Afin de garantir une bonne organisation et un traitement équitable des comptes, chaque membre doit respecter les consignes suivantes.

01

LIMITE D’ENVOI

  • Maximum de 2 fichiers JSON par jour.
  • Aucun envoi supplémentaire ne sera accepté.
02

PSEUDO DES COMPTES

  • Vous devez modifier le pseudo de chaque compte.
  • Il est interdit d’utiliser le même pseudo sur plusieurs comptes.
03

HORAIRES D’ENVOI

  • Les fichiers doivent être envoyés uniquement entre 14h00 et 16h00.
  • Aucun compte ne sera accepté en dehors de ce créneau horaire.
04

PAIEMENT EN ATTENTE

Si le paiement de votre précédent envoi n’a pas encore été effectué, il est strictement interdit d’envoyer un nouveau fichier. Attendez de recevoir votre paiement avant tout nouvel envoi.

05

MODIFICATION ET SUPPRESSION DES FICHIERS

  • Il est strictement interdit de supprimer ou de modifier un fichier JSON après son envoi.
  • Envoyez toujours le fichier JSON en premier, puis ajoutez votre description dans un message séparé.
  • En cas de correction, seule la description peut être modifiée ou remplacée. Le fichier JSON original doit rester intact.

IMPORTANT

Ces règles s’appliquent à tous les membres, sans exception. Tout non-respect de ces consignes peut entraîner le refus des comptes concernés.

Merci de votre compréhension et de votre coopération.
